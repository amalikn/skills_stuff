# Pad skill (central copy)

Operator, 2026-11-10: manage Pad's skill centrally, like the other skills, instead of a copy in each project.

| File                          | Used by                           | How it is installed                                                                                                              |
| ----------------------------- | --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `.agents/skills/pad/SKILL.md` | Codex, Cursor, Windsurf, OpenCode | `~/.agents/skills/pad` is a symlink to `.agents/skills/pad/` here                                                                |
| `.claude/skills/pad/SKILL.md` | Claude Code, fallback only        | not linked: Claude Code uses the Pad plugin (`/plugin marketplace add PerpetualSoftware/pad`, `/plugin install pad@pad`), which  |
|                               |                                   |   updates itself                                                                                                                 |

## Refresh after a Pad upgrade

```bash
cd /Volumes/Data/_ai/_skills/skills_stuff/pad && pad agent install codex && pad agent install claude   # name the tools: bare `pad agent install` only asks
git -C /Volumes/Data/_ai/_skills/skills_stuff diff -- pad/   # read what Pad changed, then commit
```

Pad writes with a plain file write into the current folder (source: `internal/cli/agents.go` `InstallForTool`, v0.19.2), so running it here updates these files in place and the symlink keeps pointing
at them. The text is Pad's: do not edit it by hand, a refresh overwrites it.

## Other projects

`pad init` in any project writes its own `.claude/skills/pad/` and `.agents/skills/pad/` copies again. Delete those two folders after `pad init` (keep `.pad.toml`); the central copy already serves
every project.
