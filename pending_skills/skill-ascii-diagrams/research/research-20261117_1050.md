# Research 2026-11-17 — existing ASCII diagram tools

Two passes, both by research agents on 2026-11-17 for skill-drawio's ASCII work (now this pack). Verbatim copies of the permissively licensed files are in skill-drawio

## Pass 2: links from the operator (MonoSketch, an mcpmarket skill, asciidiagrams.github.io)

- **tuanchauict/MonoSketch** (Kotlin/JS; Apache-2.0, GitHub API): a line end snaps to a box side within 1 cell and is stored as a ratio along that side plus an offset, so a moved box re-derives it
  (`ShapeConnectorUseCase.kt`, `LineConnector.kt`); routing is a midpoint elbow and collinear-point reduction, no obstacle avoidance (`LineHelper.kt`); joints are a 12-bit mask (4 directions by 3
  weights) ANDed with what neighbours reach (`CrossingResources.kt`); ASCII `-|+` normalised to Unicode first. VERIFIED_PRIMARY.
- **mcpmarket "ascii-diagram-generator"**: a listed Claude Code skill (Node engine on a grid, post-render border fix, four border styles); its repository returns 404 and its SKILL.md did not render,
  so its rules are UNVERIFIED and its licence unknown. Not used.
- **asciidiagrams.github.io**: 2156 diagrams from code comments (Chromium, Linux, LLVM, TensorFlow), 504 tagged by a design framework; no licence on the site repo. From `agg.json` (VERIFIED_PRIMARY):
  27 use Unicode box drawing; line width median 75, 90th percentile 80; common tags: directed graph 121, timelines 99, schematic layout 95, point annotation 67. A test corpus only, never copied into
  the pack.

## What it changed

- Stage plan (operator 2026-11-17: "staged: snap, then graph"): stage 1 snapping and checks (asciiflow idea, box-diagram checks); stage 2 graph renderer with A* after mermaid-ascii plus skill-drawio's
  channel and crossing rules; stage 3 parser after svgbob, ditaa's idea and aafigure's mask.
- Defaults: plain ASCII within 80 columns; Unicode read later, never drawn (operator 2026-11-17).
