# Personal Skills

Personal-use skill packs — single-file and multi-file specialist packs for personal productivity, wellbeing, and career management.

## Folder index

- [skills/skill-careertracker/](skills/skill-careertracker/)
  Career/job tracking and assessment workflow. Sources candidates via JobSpy, assesses roles from job ad URLs, drives three-phase build workflow (markdown → docx → PDF).

- [therapy-counselling/](therapy-counselling/)
  Conversational support skill using CBT, Motivational Interviewing, and Solution-Focused Brief Therapy. Structured session protocol, crisis escalation, and boundary enforcement. Not a substitute for licensed therapy.
  Install: `skill_manage` (Hermes) or copy SKILL.md to `.claude/skills/` or `~/.codex/skills/`.
