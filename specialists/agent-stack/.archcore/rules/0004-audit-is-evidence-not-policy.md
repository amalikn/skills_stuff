# Rule 0004 — An audit is evidence, not policy

## Rule

Do not treat an audit finding or recommendation as project truth. `REVISION_NOTES.md` records which were accepted and which were deliberately deferred; that
record is the decision, not the audit.

## Why

An audit is a list of things someone thought. Acting on an unreviewed recommendation converts one person's opinion into project policy without anyone deciding to.
