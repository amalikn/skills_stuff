# Seed parts

A file in this folder named like a reference in the seed's `Task routing` table (for example `topic-name.md`) is used as the body of that reference when `new-skill scaffold --apply` runs, under a generated front
matter. Write it as a reference body starting with a `# Title` line, in generic terms: it goes into a shared pack, and the scaffold refuses if a `forbidden_terms` name appears. A part for a reference that is not
routed is ignored and reported. Parts stay here after the build, as the record of the first draft.
