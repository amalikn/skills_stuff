# Information security manual
The Information security manual is a cyber security framework organisations can use to protect information and operational technology systems from cyber threats.
![](https://www.cyber.gov.au/themes/custom/cybergovau/assets/icons/search-header-img.svg)
## The Australian Signals Directorate produces the Information security manual (ISM)
The ISM is a cyber security framework that an organisation can use to protect their information technology and operational technology systems from cyber threats. The ISM is intended for chief information security officers, chief information officers, cyber security professionals, and information technology and operational technology managers.
![](https://www.cyber.gov.au/sites/default/files/styles/banner_desktop/public/2026-09/DEV-EPRT-01-HB.jpg?h=d1cb525d&itok=f0szjGph)
## Strengthening cyber security and resilience
Learn how the ISM helps organisations manage cyber threats to information technology and operational technology systems.
