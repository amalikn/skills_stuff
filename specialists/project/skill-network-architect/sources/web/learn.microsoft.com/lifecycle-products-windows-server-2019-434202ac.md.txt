Windows Server 2019 follows the [Fixed](/en-us/lifecycle/policies/fixed) Lifecycle Policy.

This applies to the following editions: Datacenter, Essentials, Standard

Support dates are shown in the Pacific Time Zone (PT) - Redmond, WA, USA.

## Support Dates

| Listing | Start Date | Mainstream End Date | Extended End Date |
| --- | --- | --- | --- |
| Windows Server 2019 | 11/13/2018 8:00:00 AM | 1/10/2024 6:59:59 AM | 1/10/2029 6:59:59 AM |
