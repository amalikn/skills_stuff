# Windows Server 2025

Windows Server 2025 follows the [Fixed](https://learn.microsoft.com/en-us/lifecycle/policies/fixed) Lifecycle Policy.

This applies to the following editions: Datacenter, Datacenter: Azure Edition, Essentials, Standard

Support dates are shown in the Pacific Time Zone (PT) - Redmond, WA, USA.
