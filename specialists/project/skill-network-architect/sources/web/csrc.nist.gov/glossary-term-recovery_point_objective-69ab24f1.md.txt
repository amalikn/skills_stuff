### Recovery Point Objective

**Abbreviations / Acronyms / Synonyms:**

**Definitions:**

  The point in time to which data must be recovered after an outage.  
**Sources:**

  

[NIST SP 800-34 Rev. 1](https://doi.org/10.6028/NIST.SP.800-34r1)
