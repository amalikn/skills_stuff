# Requesting access to an MDM Vendor CSR Signing Certificate

This certificate lets you sign your own Certificate Signing Requests (CSRs) or the CSRs of MDM solution customers in order to generate an MDM Push Certificate at [identity.apple.com](https://identity.apple.com/). You can then perform many of the MDM payload operations listed in the [Apple Platform Deployment guide](https://support.apple.com/guide/deployment/welcome/web).

If you’re an Account Holder of the Apple Developer Program or the Apple Developer Enterprise Program and want to generate an MDM Vendor CSR Signing Certificate, [contact us](https://developer.apple.com/contact/).
