# Rule: Review a render before anyone sees it

Status: accepted (operator feedback on self-review of visuals; sources `references/export-and-self-review.md`, `SKILL.md` standing rules; candidate confidence medium; promoted 2026-10-19 on the
operator's instruction "promote and accept")

## Rule

Export the page, crop and zoom, trace every arrow, fix what is wrong and re-render before a drawing is shown. Never send an unreviewed first render.

## Enforcement

Not mechanical. Recorded as a rule because the failure (showing a broken render) recurred.
