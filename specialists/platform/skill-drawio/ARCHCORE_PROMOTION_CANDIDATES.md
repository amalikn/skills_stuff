## Review of the first draft (2026-10-19)

The operator asked whether the first draft's entries were correct before promoting them. Found and fixed:

1. Format: it was one table without the per-type sections, sources or confidence the pattern asks for
   (`/Volumes/Data/_ai/_skills/skills_stuff/specialists/project/skill-ai-it/patterns/archcore-routing.md`, "Candidate report format"); one entry was sourced from a CHANGELOG, which the pattern
   excludes as a source.
2. Hand-made drawings: the rule was marked "not mechanical" and the code did not honour it (`--write` would overwrite any file). `write_drawing` now refuses a file without the generated banner, with a
   test.
3. Profile: "the engine holds no project's values" was false: two `Profile` defaults were unified-network-controller's (`default_tier=2`, band title "Credentials and stores"). Both are neutral now (0,
   "Stores and secrets"); that project passes its own values, and its drawing stays byte-identical.
4. Audits: "every routed page" overstated it; flow pages are drawn by draw.io's router and are not audited.
5. Byte identity: "enforced by the consumer's drift check" overstated it; the consumer's check runs only in that project.

Added: the runtime ADR, the package-layout ADR (medium), and rules for uncompressed output, the write-back contract and generic pack text, plus a spec candidate and a guide candidate.
