## Parallels Desktop plus Vagrant FAQs

### [What is Vagrant?](#accordion-faq_collapse1)

Vagrant is a tool for building and distributing development environments. It provides the framework and configuration format to create and manage complete portable development environments. These development environments can live on your computer or in the cloud, and are portable between Windows, macOS, and Linux.

### [What is Parallels Provider?](#accordion-faq_collapse2)

The Parallels provider for Vagrant is a plugin officially supported by Parallels that enables users to manage portable development environments in virtual machines powered by Parallels Desktop for Mac.

### [Can I test different scenarios with Vagrant and Parallels Desktop?](#accordion-faq_collapse5)

Yes, you can test different scenarios in different operating systems using the Vagrant Parallels Provider integration, which lets you [run multiple VMs](/glossary/virtual-machine/) with Parallels Desktop on your Mac, all powered by Vagrant. Check out the [documentation](https://parallels.github.io/vagrant-parallels/docs/) to learn more.

### [What if I am unable to install the Vagrant plugin for Parallels Desktop?](#accordion-faq_collapse6)

If you are having issues installing the Vagrant plugin, ensure that you are using Parallels Desktop Pro or Business Edition and that you have Xcode Command Line Tools installed. If you are still having trouble, review the steps on how to [install the Vagrant plugin](https://kb.parallels.com/en/124500) for Parallels Desktop.

### [Is the Parallels Provider for Vagrant free?](#accordion-faq_collapse12)

Yes, the Parallels Provider for Vagrant is free and open for contributions on [GitHub](https://github.com/Parallels/vagrant-parallels).
