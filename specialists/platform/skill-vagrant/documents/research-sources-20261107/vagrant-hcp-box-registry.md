## Vagrant Cloud

Vagrant Cloud serves a public, searchable index of Vagrant boxes

Note

HCP Vagrant is being [deprecated](/hcp/docs/vagrant/hcp-vagrant-eol). Customers using Vagrant boxes hosted on the HCP Vagrant registry must find a new provider and re-host their boxes. As of October 1, 2026, new boxes can no longer be created in HCP Vagrant. Existing box deployments will continue to operate until the end of operations date of December 31, 2026. After that time, all deployments will be decommissioned.

For Vagrant Cloud questions, feedback, or feature requests, please submit a ticket to
HashiCorp Support.

[Click here](/vagrant/vagrant-cloud/support) for instructions on submitting a support ticket.

Vagrant Cloud provides the following features for Vagrant:

* [Vagrant Box Catalog](/vagrant/vagrant-cloud/boxes/catalog)
* [Vagrant Box Creation](/vagrant/vagrant-cloud/boxes/create)
* [Vagrant Box Versioning](/vagrant/vagrant-cloud/boxes/lifecycle)
