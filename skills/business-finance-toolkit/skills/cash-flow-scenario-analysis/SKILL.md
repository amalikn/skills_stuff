# Cash Flow and Scenario Analysis

Model timing, not only profitability. List opening cash, deposits, acquisition payments, duties/taxes, freight, repairs, overhead, sale timing, finance, and contingency. Create downside cases for price, freight, FX, repair cost, delay, sell-through, and return exposure. Preserve the inputs and run manifest for every scenario.
