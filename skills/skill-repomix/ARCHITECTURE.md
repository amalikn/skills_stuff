# Architecture

```text
Skill guidance
  -> language detection
  -> profile selection
  -> wrapper orchestration
  -> Repomix CLI or MCP
  -> validated context output
```

## Layers

- `SKILL.md`: operational workflow
- `profiles/`: language-specific scope
- `patterns/`: reusable decision rules
- `templates/`: files installed into projects
- `scripts/`: execution and installation
- `tests/`: validation fixtures and regression tests
