# Conventions — skill-ansible-repo-intelligence (skill-ari)

## Naming

| Thing | Pattern | Example |
|---|---|---|
| Time-bound docs | `<slug>-YYYYMMDD_hhmm.md` | `...-implementation-report-20260703_1420.md` |
| Python modules | `snake_case.py`, one responsibility per module | `inventory_flavors.py` |
| Node IDs | `<kind>:<rel-path>[:<doc>:<idx>]` | `task:roles/dns/tasks/main.yml:0:3` |
| Edge IDs | `edge:<type>:<stable-hash>` | `edge:notifies:ab12…` |
| Diagnostic codes | `ARI<nnn>_<UPPER_SNAKE>` | `ARI006_POSSIBLE_VARIABLE_PRECEDENCE_CONFLICT` |

## Code style

Project-specific rules only (not Python defaults):

- **Never raise from analyzers.** Parsing/loading returns error-carrying results
  (`LoadedFile.ok`, `parse_error`), never exceptions — a scan must never crash on
  one bad file. Emit a diagnostic instead.
- **Determinism is a hard rule.** Sort every emitted collection by a stable key.
  No `Date.now()`/timestamps inside content-derived hashes. No random IDs.
- **Parse-only, never execute.** Jinja: `.parse()` + AST walk, never `render()`.
  Vars plugins: `ast.parse`, never import. Vault: detect, never decrypt.
- **Bounds are defaults, not options to forget.** Query 25/1hop, impact 50/3hop;
  every traversal reports `truncated` + reason.
- **Config over hardcoding.** Significance and precedence live in schema-validated
  `config/*.yaml`, not in code branches.
- **Module boundaries are fixed** (see `ARCHITECTURE.md`). Query and impact must
  share `traversal.py` — never duplicate reachability logic.
- **ruamel `typ="rt"`**, not `"safe"` (line numbers). Registered `!vault`/`!unsafe`
  constructors are opaque.

## Testing

- Every gate has a test. Fixture: `tests/fixtures/multi_role_repo` (generated by
  `tests/_gen_fixture.py`). Run: `just test` or `<venv>/bin/python -m pytest tests -q`.
- Determinism is tested end-to-end (byte-identical reruns).

## Anti-patterns

- Emitting per-role / per-index files (validator forbids — lean output only).
- Matching impact roots by bare basename (explodes the set — exact/dir-prefix only).
- Claiming a runtime variable winner when higher-precedence inputs are unknown.
- Self-grading the benchmark's correctness half.
